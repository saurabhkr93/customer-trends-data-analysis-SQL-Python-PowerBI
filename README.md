# 👨🏻‍💻 Customer Behavior Data Analyst Portfolio Project

An end-to-end data analytics project demonstrating an industry-standard workflow for understanding customer purchasing behaviour, identifying business trends, and generating actionable insights.

This project covers the complete data analytics lifecycle, from data preparation and exploratory analysis to SQL-based business analysis, interactive Power BI dashboards, and business reporting.

It demonstrates how Python, SQL, and Power BI can be used together to transform raw customer transaction data into meaningful business intelligence.

## 🎯 Who Is This Project For?

- 📊 Aspiring Data Analysts looking to build a strong portfolio project.
- 📚 Students learning Python, SQL, and Power BI.
- 💼 Candidates preparing for Data Analyst, Data Science, and Product Analytics interviews.
- 🚀 Anyone interested in understanding customer purchasing patterns through data.

---

## 📌 Project Overview

The objective of this project is to simulate a corporate-grade, end-to-end data analytics workflow and demonstrate the ability to transform raw data into strategic business insights.

The project covers four major stages:

**1. Data Preparation, Modeling & Exploratory Data Analysis (Python)**

- Import and explore the raw dataset.
- Identify missing values and inconsistencies.
- Clean and transform the data.
- Prepare structured data for further analysis.

**2. Data Analysis (SQL)**

- Load processed data into a SQL database.
- Perform customer and transaction-level analysis.
- Write SQL queries to investigate customer segments, loyalty, and purchasing behaviour.
- Answer important business questions using SQL.

**3. Visualization & Insights (Power BI)**

- Connect the SQL database to Power BI.
- Develop an interactive dashboard.
- Visualize customer trends, purchasing patterns, and key business metrics.
- Present insights through meaningful charts and KPIs.

**4. Reporting & Presentation**

- Prepare a structured project report.
- Summarize important findings.
- Develop actionable business recommendations.
- Create a presentation to communicate insights to stakeholders.

## 🚀 How to Use This Project

### 1. Clone the Repository

Clone the repository using Git:

```bash
git clone https://github.com/saurabhkr93/customer-trends-data-analysis-SQL-Python-PowerBI.git

cd customer-trends-data-analysis-SQL-Python-PowerBI
```

### 2. Open the Python Notebook

Open `Customer_Shopping_Behavior_Analysis.ipynb` in Jupyter Notebook.

The notebook contains:

- Data Import
- Data Exploration
- Data Cleaning
- Exploratory Data Analysis
- Connection to SQL Database

### 3. Load Data into SQL Database

Load the processed dataset from the Python notebook into your preferred SQL database.

Supported database options:

- MySQL
- PostgreSQL
- Microsoft SQL Server

Steps:

1. Create a database.
2. Establish a database connection from Python.
3. Execute the Python code to load the processed data.
4. Open `customer_behavior_sql_queries.sql`.
5. Execute the SQL queries.
6. Analyze customer behaviour and answer the business questions.

### 4. Build the Power BI Dashboard

Open `customer_behavior_dashboard.pbix`.

Steps:

1. Open Power BI Desktop.
2. Connect to the SQL database.
3. Load the required tables.
4. Create the required measures and visualizations.
5. Build interactive dashboard pages.
6. Explore customer behaviour and business insights.

### 5. Create Project Report and Presentation

Prepare a structured project report covering:

- Project Introduction
- Business Objectives
- Data Preparation
- Exploratory Data Analysis
- SQL Analysis
- Key Findings
- Business Recommendations
- Conclusion

Create a presentation deck using Gamma AI or another presentation tool to communicate the results effectively.
